Discrete Math

論理回路のサンプル

一覧へAND・OR・NOT・XOR・NOR同期回路

01 / MEMORY

SRフリップフロップ

2個のNORゲートを交差帰還し、入力が0に戻っても1ビットを保持
Q=0

Q=¬(R∨Q̅)　/　Q̅=¬(S∨Q)　/　S=R=0 のとき前の値を保持

02 / COMBINATIONAL

1ビット半加算器

2つの入力を加算し、XORで和、ANDで桁上がりを出力
S=0 / C=0

S=A⊕B　/　C=A∧B

03 / COMBINATIONAL

1ビット全加算器

2個の半加算器を回路素子として接続し、ORで桁上がりを統合
S=0 / Cout=0

HA1(A,B)→(P,C1)　/　HA2(P,Cin)→(S,C2)　/　Cout=C1∨C2

04 / MEMORY ARRAY

4ビットレジスタ

入力制御付きDフリップフロップを4個並列にし、共通CLKで同時保存
Q=0000

Q[3:0]⁺ = D[3:0]（4個すべてが同じ CLK ↑ を受ける）

05 / SEQUENTIAL ADDER

4ビット連続加算器

4個の全加算器をキャリー接続し、結果とCoutを5ビットレジスタへ保存
cycle 0
3 5

加算結果は常に変化し、CLK ↑ の瞬間だけ出力レジスタへ保存されます。
